# SDKs

| Path | Package | Registry |
| --- | --- | --- |
| [`typescript/`](typescript) | `@tinyhumansai/openintents` (SDK + `openintents` CLI) | npm |
| [`python/`](python) | `openintents` (sync + async) | PyPI |
| [`rust/`](rust) | `openintents` (async; CLI behind `--features cli`) | crates.io |
| [`skill/openintents/`](skill/openintents) | Agent skill (`SKILL.md`) | |
| [`plugin-claude/`](plugin-claude) | Claude Code plugin (MCP server + skill) | this repo's marketplace |
| [`examples/`](examples) | One runnable example per language | |

All three SDKs implement the same surface, generated by hand from
[`../spec/openapi.yaml`](../spec/openapi.yaml). Every create (intents,
customers, top-ups) and `cancel` sends an `Idempotency-Key`; intents can be
bought for, and listed by, a `customer`. The spec's preview endpoints
(profiles, sessions, event streams) join the SDKs once the API serves them.

| Operation | TypeScript | Python | Rust |
| --- | --- | --- | --- |
| Create | `intents.create` | `intents.create` | `create_intent` |
| Retrieve | `intents.get` | `intents.get` | `get_intent` |
| List / all pages | `intents.list` / `listAll` | `intents.list` / `list_all` | `list_intents` |
| Cancel | `intents.cancel` | `intents.cancel` | `cancel_intent` |
| Wait | `intents.wait` | `intents.wait` | `wait` |
| Balance (a customer's) | `balance.get({ customer })` | `balance.get(customer=)` | `balance` / `balance_for` |
| Customers: create, retrieve, update | `customers.create` / `get` / `update` | `customers.create` / `get` / `update` | `create_customer` / `get_customer` / `update_customer` |
| Customers: list / all pages | `customers.list` / `listAll` | `customers.list` / `list_all` | `list_customers` |
| Top-ups: create, retrieve | `topups.create` / `get` | `topups.create` / `get` | `create_topup` / `get_topup` |
| Webhooks | `verifyWebhook` | `verify_webhook` | `webhooks::verify_webhook` |

Versions move together; `node sdk/bump-versions.mjs <patch|minor|major>` bumps
all of them.
